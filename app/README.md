# Stream

Stream is an iPhone application that will display an H.264 camera stream received over UDP. The project currently contains the initial SwiftUI application shell; the camera layout and video receiver will be added in later commits.

## Requirements

- macOS with Xcode 26.6 or another Xcode version capable of targeting iOS 17
- An iOS 17 or newer Simulator for local testing

No third-party dependencies are required for the initial application.

## Open and run

1. Open `Stream.xcodeproj` in Xcode.
2. Select the `Stream` scheme.
3. Select an iPhone Simulator.
4. Choose **Product > Run**.

The initial app displays the word “Stream”.
